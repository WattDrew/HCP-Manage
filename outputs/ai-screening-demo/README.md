# AI 初筛标准交互 demo

入口：`index.html`。沿用现有语贝工作台界面，默认打开「眼科数据采集项目 → 项目设置」。

- 点击「AI 初筛标准 → 修改」，可编辑最低对话轮次及医生回复最低总字数，默认 20 轮、500 字。
- 两项配置均须为正整数；支持保存、取消及恢复默认值。
- 配置按项目 ID 保存在当前浏览器 localStorage，刷新后保留。
- 「审核设置」点击「修改」进入弹窗配置「自动终审通过」，点击「保存」后生效，取消不保存；默认关闭，按项目保存。开启后，该项目后续初审通过的数据自动终审通过。
- 已移除初筛配置弹窗顶部提示和整个「初筛效果演示」模块。未接入真实模型或审核服务。

本目录依赖工作区 `assets/` 中现有的组件和样式，保留了原有项目文件。

企业采集数据的批量操作新增「指定标签打标」：展示当前项目标签体系及已产生的标签，支持分类浏览、搜索、多选与全选；确认后对已选记录执行所选标签识别。未选标签及手动标签保留；未选择记录或标签时禁止提交。打标使用本地原型的规则推断与处理状态，未接入真实 AI 服务。

初筛配置已验证修改保存、刷新保留、空值拦截、取消及恢复默认值。审核状态转换已验证开关两种情况下的数据状态和计数；脚本通过 `node --check`。
