# 企业采集数据

入口：工作台左侧「客户端 → 企业采集数据」。企业切换使用可搜索下拉菜单。

## 已实现

- 右上角添加企业：输入完整 ID → 查询企业 → 确认添加；重复企业可直接切换。
- 按企业隔离项目，项目状态切换、搜索和分页；详情包含数据集、数据分析，默认打开数据集；企业下拉仅出现在项目列表页。
- 数据详情复用需求端的对话内容、语音控件、数据日志（含历史对话及协议查看）、采集对象信息展示；姓名、手机号、执业凭证保持脱敏。抽屉宽度和状态标签与需求端一致，移除简化版信息表和预览，不提供审核、编辑或导出。只读记录的驳回原因独立传入，避免读取其他记录的本地审核原因。
- 切换企业重置详情、筛选与抽屉；当前浏览器保存已添加企业与上次选择。
- 企业下拉仅包含已添加企业。无企业、无项目、查询失败、类型不匹配及权限不足均有反馈。

## 演示数据

- 默认已添加：ENT-10001（华东医疗数据服务中心）、ENT-10002（华南医学调研有限公司）。
- 可添加：ENT-10003（北京博采医疗科技有限公司，无项目）。
- 权限不足：ENT-10004；采集端企业：ENT-20001；其他 ID：不存在。
- 数据集列表为样本，区别于累计采集量；分析页明确展示统计口径。

## 后端接入约束

当前仓库为静态原型。演示目录、权限标记和浏览器存储不能作为生产环境鉴权。

正式接入时需提供：当前管理租户的已添加企业查询、按完整 ID 查询可关联企业、添加企业关联、企业项目列表、项目接口列表及详情、数据集列表及详情、项目分析。

企业关联应存于服务端，当前管理租户内共享；新增关联须校验管理权限及既有企业访问授权，不因知道企业 ID 自动授权。所有业务查询都须校验登录账号、当前管理租户、企业关联、项目归属和记录归属。权限撤销后立即拒绝查询。企业查询应避免向无权账号透露企业资料。返回的接口数据不包含密钥，HCP 信息沿用脱敏规则。

本功能独立代码位于 assets/enterprise-data.js 与 assets/enterprise-data.css；由 index.html 加载并在现有 assets/app.js 的菜单与页面渲染处接入。assets/app.jsx 是旧版本源文件，本次未用其覆盖已有工作台。

## 验证

运行 `node outputs/enterprise-data/verify.cjs` 验证企业隔离、添加异常、重复关联、只读页签、筛选、抽屉、切换重置、空态及刷新持久化；运行 `node --check assets/enterprise-data.js` 和 `node --check assets/app.js` 检查语法。

浏览器连接器拒绝读取 file:// 本地页面，因此未完成真实浏览器视觉验证；自动交互验证使用隔离的组件状态与元素树。

## 页面统一

需求端与企业查看页共用 assets/demand-data-views.js 的 Dataset、Analysis 组件。数据集统一采集对象、采集用 E 人、来源接口、对话轮次、数据状态、时间、操作列；分段筛选显示全部、待审核、终审未通过、终审通过及数量，每页 5 条。移除企业页独立的搜索和状态下拉。数据分析复用采集完成度、采集点阵和待采集/待审核/已审核图例。数据仍以各自的项目来源为准，企业页维持只读。添加企业弹窗仅保留 ID 输入、查询结果与操作，移除两段辅助说明。
